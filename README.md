# Samaky for Schools (demo)

A clickable demo of the Samaky Service Learning Office dashboard, shown with a University of St. Thomas sample.

- Live site: https://school.samaky.co (once DNS is set up)
- Visit the site root. `index.html` is a frame that shows each screen, so the address bar always stays on the bare domain. The Home screen itself is `SchoolHome.html`.
- All students, numbers and records shown are sample data.
